# Security Policy

## Reporting a vulnerability

Please report security issues privately. Do **not** open a public GitHub issue for vulnerabilities.

Use GitHub's private reporting: [report a vulnerability](https://github.com/peragolabs/spendmux/security/advisories/new).

Include a clear description, steps to reproduce if possible, and impact. We will acknowledge receipt and work with you on a fix.

## Scope

This policy covers this repository: the self-hosted BYOK proxy, vault, and web app. For the paid hosted version, see [spendmux.com](https://spendmux.com).
